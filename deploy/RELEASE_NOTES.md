# 神树 Shen Shu v0.1 预览版

在六边形土地上培育神树的卡牌构筑游戏。每回合把牌接到枝头，养分从树心流向所有末梢；树的形状就是牌型，长得越茂盛，收获越多。一局三年，每年春夏秋冬加一场天灾。

## 两种玩法

### 方式一：下载安装（推荐，画质最好）
1. 下载 **`ShenShu-0.1-Setup.exe`**（约 64MB）。
2. 双击运行，按提示安装。不需要管理员权限，也不需要另装 Godot，游戏运行时已经打包在里面。
3. 装好后从桌面或开始菜单的「神树」进入。卸载可在「设置 → 应用」或开始菜单的「卸载神树」里完成。

> Windows 可能弹出「Windows 已保护你的电脑」（安装包没有付费数字签名）：点「更多信息」→「仍要运行」。

不想安装的话，可以下载 **`ShenShu-0.1-win64.zip`**，解压后双击 `ShenShu.exe` 直接玩（`ShenShu.exe` 和 `ShenShu.pck` 要放在同一个文件夹）。

系统要求：Windows 10/11 64 位；支持 Vulkan 或 OpenGL 3.3 的显卡（集显即可）。

## 操作
点选或拖拽手牌到发光格；数字键 1–5 选牌，空格结束回合（脉动中按住空格加速），按住 Tab 看图解，P 修剪，R 重抽，L 记录，H 规则，Esc 取消。第一次玩建议先走一遍主菜单里的「新手指导」。
