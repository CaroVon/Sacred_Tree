# 神树 · 游戏美学调研：我们缺什么、怎么补

> 对象：炉石传说（Hearthstone）、Balatro、月圆之夜、杀戮尖塔（Slay the Spire），另加 Inscryption（3D 桌面 + 2D 卡牌的混合范例）。
> 目的：不抄风格，只拆“美学要素”——让一款以规则和文字为主的卡牌游戏，**看起来、摸起来像一个游戏**的那些东西。
> 神树的风格基调不变：**失落文明的古典典藏图册**（哑光旧色、雕版细线、纸张颗粒、古典建筑 × 几何植物）。

---

## 1. 各家的美学要素拆解

| 游戏 | 它最强的美学要素 | 对应的技术手段 |
|---|---|---|
| **炉石传说** | **实体桌面 / 重量感**：牌桌是一个立体的小场景（四角有可互动的摆件）；出牌时卡牌抬起→砸下→尘土冲击波→镜头震动，强度随费用 / 稀有度递增；法力水晶、回合按钮都是“实物” | 3D 场景 + 2D 卡牌；分级冲击反馈；实物化 UI |
| **Balatro** | **Juice（手感汁水）与计分演出**：每一张牌、每个小丑依次触发，数字弹出、抖动、音高逐级上扬；筹码 × 倍率最后砸下；分数超过目标时燃烧；卡牌持续微摆、跟随鼠标做 3D 倾斜；背景是缓慢流动的着色器 | 顺序化计分动画；伪 3D 透视着色器；音高递进；待机动画 |
| **月圆之夜** | **绘本式的环境叙事**：每个界面都是一幅“场景插画”而不是表单；地图节点像桌游棋子；统一的手绘边框语言；章节过场 | 场景化 UI；统一边框/装帧体系；叙事过场 |
| **杀戮尖塔** | **可读性美学 + 实物化资源**：意图图标、能量球、抽牌堆/弃牌堆计数与飞牌动画、洗牌动画；遗物栏触发时闪烁；稀有度牌框；关键词悬停说明 | 资源实体化；状态变化必有动画；颜色/框体编码价值 |
| **Inscryption** | **2D 卡牌落在 3D 桌面**：低多边形 3D 牌桌、灯光与烛影、卡牌是有厚度的纸片、天平/摆件做数值可视化 | 透视相机 + 灯光阴影 + 桌面道具承载数值 |

## 2. 神树缺失的美学要素（按优先级）与补齐方案

### ① 重量感 / 物理性（Hearthstone、Inscryption）
- **现状**：卡牌、地块都是平面多边形，落牌只有一个墨迹扩散。
- **补齐**：
  - 牌桌 3D 化：地块是有厚度的六棱柱石板，已放的牌是更厚的“石片”，有真实灯光与投影。**（阶段 2）**
  - 落牌：石片从空中落下 → 回弹 → 尘土粒子 → 轻微镜头震动；**冲击强度分级**（普通 / 分枝 / 嫁接与金色牌）。**（阶段 2–3）**
  - 牌堆、弃牌堆是看得见的一叠牌，厚度随张数变化。**（阶段 1 已完成）**

### ② 计分演出（Balatro）——神树最核心的缺口
- **现状**：脉动时枝干一起点亮，末梢冒 “+N”，分数直接跳。
- **补齐**（阶段 3）：
  1. 养分沿枝干逐段流动（已有），**每个末梢收获时依次弹出数字并飞入顶部分数**；
  2. 每个末梢的提示音**音高逐级上扬**（`Game.sfx` 已支持 pitch）；
  3. 牌型（长茎 / 星芒 / 闭环 / 对称）和整树倍率最后**盖章砸下**；
  4. 分数槽填满，**超过目标时金光迸发**；
  5. 按住空格 2 倍速，照顾老玩家。

### ③ 待机生命感（Balatro、炉石）
- **现状**：除了卡槽呼吸，画面静止。
- **补齐**：手牌轻微摇摆；3D 场景里的光束与浮尘；树心缓慢呼吸发光；神庙背景中有微弱的视差。**（阶段 3）**

### ④ 环境叙事 / 季节感（月圆之夜）
- **现状**：四季只是文字“季节特性：……”，天灾只是红字。
- **补齐**（阶段 3）：
  - **四季改变 3D 牌桌的光照与色调**：春（青绿晨光）、夏（暖金正午）、秋（赭红斜阳）、冬（冷灰月光）。
  - **天灾天气**：干旱 = 热浪扭曲 + 焦黄滤色；雷击 = 间歇闪光；虫害 = 飞虫粒子。
  - 主菜单从一张表单变成**一个场景**：神庙庭院里的神树、飘落的花粉。**（阶段 4）**

### ⑤ 价值 / 稀有度的视觉语言（杀戮尖塔、炉石）
- **现状**：所有牌用同一种框，只有类别色铭牌。
- **补齐**：按类别 + 强度区分牌框装饰；金色系的牌（金果等）加**金箔反光着色器**（古典鎏金，而不是“闪卡”）。**（阶段 3）**

### ⑥ 触发可见（Balatro 小丑、尖塔遗物）
- **现状**：器物只是一排小图标，生效时毫无表现。
- **补齐**：器物立在牌桌上缘的石座上（3D），**生效时跳起发光**；悬停时聚光并缓慢旋转。**（阶段 2）**

### ⑦ 手牌的“桌面感”（全部参照对象）
- **现状**：手牌是一排平铺的按钮，抽牌没有动画。
- **补齐**：扇形手牌，悬停抬起放大、邻牌让开；**抽牌从牌库沿弧线飞出并翻面**；出牌飞向目标格；重抽扫进弃牌堆。**（阶段 1 已完成）**
  - 伪 3D 倾斜着色器，卡牌跟随鼠标倾斜。**（阶段 3）**

### ⑧ 交互提示（炉石瞄准箭头）
- **补齐**：拖拽时从卡牌长出一根“枝条”曲线指向目标格；可放置格在 3D 中微微抬起；自定义叶形光标。**（阶段 3）**

### ⑨ 主题化转场
- **现状**：一张纸从右往左擦过。
- **补齐**：墨晕扩散（遮罩着色器），配合场景切换。**（阶段 3）**

### ⑩ 声音层（全部参照对象都非常强）
- **现状**：7 个短音效。
- **建议**（本次不做，记录在此）：环境底噪（风、鸟、神庙回声）随季节切换；脉动计分的音阶上扬；落牌按冲击等级分三档音效；一段极简的主题音乐。
